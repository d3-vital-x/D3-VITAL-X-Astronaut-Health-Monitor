# 09 | Research Documentation

## References, Citations, and Research Record

### 1. Purpose

This directory maintains the supporting scientific documentation for the D³ VITAL-X Research Engine Framework.

It provides a structured location for references, methodological sources, dataset citations, and supporting research records.

### 2. Documentation Scope

Research documentation may include:

- Peer-reviewed journal articles.
- Original methodological publications.
- IAAFT and surrogate-data literature.
- Signal-processing and spectral-analysis references.
- Information-theoretic and statistical-method references.
- Dataset documentation and access records.
- Software and library documentation.
- Relevant NASA and mission-data documentation.

### 3. Citation Requirements

Each reference should provide, where available:

- Author or institutional author.
- Publication year.
- Full title.
- Journal, publisher, or repository.
- DOI or stable URL.
- Access date for online resources, where appropriate.

Dataset citations should identify the source, version or release, access location, and applicable usage conditions.

### 4. Research Traceability

References should be linked to the methods, datasets, or claims they support.

A citation must not be used to imply that a source validates a result it did not investigate.

In particular, general IAAFT literature does not independently validate the D³ VITAL-X experimental result or establish clinical performance.

### 5. Recommended Documentation Records

This directory may contain:

- `references.md` — consolidated bibliography.
- Dataset reference records.
- Methodological source notes.
- Software and dependency references.
- Research-version and publication records.

Only verified references and actually used sources should be listed as project references.

### 6. Research Integrity

The project distinguishes between:

1. Published findings from external sources.
2. Results generated by D³ VITAL-X experiments.
3. Interpretations and hypotheses proposed by the research team.
4. Future work that has not yet been implemented or validated.

This separation supports transparent scientific communication and independent review.
