# 03 | Validation Results

## Computational Outputs and Quantitative Evaluation

### 1. Purpose

This directory contains the numerical outputs and comparison artifacts generated by the extended IAAFT surrogate spectral-matching experiment.

The purpose is to make computational behavior inspectable through structured data rather than relying solely on narrative claims or visual interpretation.

### 2. Experimental Configuration

The reported experiment used:

- 80,000 ECG rows.
- 6 channels.
- 10 replicates per channel.
- 60 total trajectories.
- Iteration checkpoints at 200, 300, 400, and 500.
- Random seed `20261114`.

### 3. Principal Data Artifacts

The directory is intended to contain the following CSV outputs:

| Artifact | Description |
|---|---|
| `iaaft_extended_raw.csv` | Raw or replicate-level measurements from the extended experiment. |
| Summary CSV | Aggregated metrics across channels, replicates, and iteration checkpoints. |
| Comparison CSV | Comparative evaluation of spectral error between iteration checkpoints. |

The exact column definitions and measurement units should be documented alongside the corresponding output files.

### 4. Reported Computational Observation

Mean spectral error decreased as the iteration checkpoint increased across the six tested channels.

The maximum reported reduction from 200 to 500 iterations was:

**56.44% — MA_MLII channel**

This value represents a relative reduction in the reported spectral-error metric under the tested experimental configuration.

It must not be interpreted as a 56.44% improvement in clinical accuracy, anomaly detection, astronaut health assessment, or diagnostic performance.

### 5. Validation Interpretation

The current results support a limited computational observation:

- Spectral-matching error can be measured across iteration checkpoints.
- Channel-level behavior can be compared.
- Replicate variability can be quantified.
- The experiment can produce structured outputs for independent review.

They do not independently establish:

- Clinical validity.
- Medical diagnostic accuracy.
- Astronaut-specific health prediction.
- Operational readiness for spacecraft deployment.
- Generalization to unseen biomedical populations.

### 6. Data Integrity

Raw, summary, and comparison outputs should retain consistent experiment identifiers, channel labels, replicate identifiers, checkpoint values, and configuration metadata.

Where applicable, file hashes and provenance records should be maintained in `05_REPRODUCIBILITY/`.

---

**Interpretation principle:** Report measured computational behavior; do not convert it into an unsupported medical or operational claim.
